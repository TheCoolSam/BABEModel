To evaluate the systemic interactions between algorithmic content moderation and interpersonal relationships, we implement a rigorous $2 \times 2$ factorial experimental design. This design systematically crosses the presence of two primary independent variables: the platform's Bridging Algorithm and the co-evolution of Dyadic Trust. This configuration yields four distinct experimental conditions:
\begin{enumerate}
    \item \textbf{Baseline (Bridge OFF, Trust OFF):} Opinions evolve via biased assimilation and behavioral entrenchment, but interpersonal relationships remain static at a uniform, neutral trust level ($T_{ij} = 0.5$), and the platform performs no content moderation.
    \item \textbf{Bridge Only (Bridge ON, Trust OFF):} The bridging algorithm is active, but dyadic trust remains static and does not co-evolve with opinion dynamics.
    \item \textbf{Trust Only (Bridge OFF, Trust ON):} Dyadic trust co-evolves dynamically based on opinion interactions, but no platform-level algorithmic intervention is deployed.
    \item \textbf{Full Model (Bridge ON, Trust ON):} Both the bridging algorithm and dynamic dyadic trust co-evolution are active, allowing us to capture their mutual feedback loops.
\end{enumerate}

\subsection{Model Hyperparameters and Topology}
We initialize a population of $N = 500$ state-vector agents embedded in a scale-free network topology generated using the Barab{\'a}si-Albert (BA) model \cite{Barabasi1999} with an attachment parameter of $m = 3$. This scale-free structure reflects the degree distributions and hub-centric properties characteristic of real-world social media networks. Opinions are initialized in a two-dimensional issue space ($N_{\text{issues}} = 2$) using a bipolar configuration, splitting the population into two opposing camps centered around $\pm 0.7$ with uniform noise. This split represents an already-polarized platform environment. 

Cognitive resistance is normally distributed across agents with mean $\mu_{\beta} = 4.0$ and standard deviation $\sigma_{\beta} = 1.5$ (floored at $\beta_{\text{min}} = 0.5$). When active, dynamic trust co-evolves with opinion dynamics: trust modulation shifts influence weights upward by $\alpha = 0.3$, trust accumulates by $\delta_+ = 0.02$ upon successful assimilation, and erodes by $\delta_- = 0.05$ upon backfire conflict, alongside a passive decay rate of $\lambda = 0.001$ per step. When the bridging algorithm is active, it intercepts interactions in the Latitude of Rejection with an efficacy of $E = 46\%$, neutralizing the backfire and providing a healing bonus of 2 points to the agent's behavioral frustration. 

For each of the four experimental conditions, we execute $R = 30$ independent replications. Each simulation runs for $S = 200$ steps, which is sufficient for the system to reach a stable steady-state. To ensure rigorous reproducibility in compliance with JASSS guidelines, all simulations are initialized using a centralized master random seed ($Seed = 42$), allowing exact reconstruction of the network structures and interaction sequences.

\subsection{Statistical Methodology}
To analyze the simulation outputs, we extract the final step data from all 120 runs. Given that opinion distributions and user active states often exhibit non-normality, we employ non-parametric statistical methods. 

First, we perform pairwise comparisons across all six unique pairs of conditions using the two-sided \textbf{Mann-Whitney U test} \cite{Cohen1988}, a non-parametric rank-sum test that requires no assumptions regarding normality or equal variances. To evaluate the standardized magnitude of differences, we compute \textbf{Cohen's d} effect sizes \cite{Cohen1988}, interpreting the effect magnitudes based on standard thresholds: negligible ($|d| < 0.2$), small ($|d| < 0.5$), medium ($|d| < 0.8$), and large ($|d| \ge 0.8$). 

Second, we construct non-parametric \textbf{95\% Bootstrap Confidence Intervals} for the mean of each metric using 10,000 resamples to capture the empirical distribution of the statistics. Third, because conducting six pairwise comparisons increases the probability of Type I errors, we apply the conservative \textbf{Bonferroni correction} independently to all pairwise comparisons and interaction tests, ensuring family-wise error rate control at $\alpha = 0.05$. 

Finally, since the simulations are paired by run ID (sharing identical underlying network topologies and interaction schedules), we perform a seed-paired \textbf{Interaction (Moderation) Analysis}. We calculate the paired differences of the bridging algorithm's effect under static trust ($(Bridge Only) - (Baseline)$) and compare them to the bridging algorithm's effect under dynamic trust ($(Full Model) - (Trust Only)$) using the Mann-Whitney U test. This allows us to statistically evaluate whether the presence of dynamic trust significantly moderates the systemic impact of algorithmic content moderation.
