We map the co-evolutionary dynamics above with a $2 \times 2$ factorial design crossing the Bridging Algorithm and Dyadic Trust co-evolution:
\begin{enumerate*}
    \item \textbf{Baseline (Bridge OFF, Trust OFF):} Biased assimilation and entrenchment under static neutral trust ($T_{ij} = 0.5$).
    \item \textbf{Bridge Only (Bridge ON, Trust OFF):} Bridging active; trust static.
    \item \textbf{Trust Only (Bridge OFF, Trust ON):} Trust co-evolves; no bridging.
    \item \textbf{Full Model (Bridge ON, Trust ON):} Bridging and trust co-evolve together.
\end{enumerate*}

\subsubsection{Model Hyperparameters and Topology}
The model embeds $N = 500$ agents in a Barab{\'a}si--Albert network~\citep{Barabasi1999} with attachment parameter $m = 3$. Opinions occupy $K = 2$ issues under bipolar initialization: each agent receives pole $\pi_i \in \{-1,+1\}$ with equal probability, and each issue is set to $\pi_i \cdot U(0.4,1.0)$ (clipped to $[-1,1]$), so expected absolute extremity is $0.7$.

Cognitive resistance $\beta_i$ is drawn $\mathcal{N}(\mu_{\beta}=4.0, \sigma_{\beta}=1.5)$ with floor $\beta_{\min}=0.5$. When enabled, trust shifts influence by $\gamma_T=0.3$, gains $\delta_+=0.02$ on assimilation, loses $\delta_-=0.05$ on backfire, and decays at $\lambda=0.001$ per step on all edges after interactions. Bridging intercepts Latitude-of-Rejection events with efficacy $E=46\%$ and grants a two-point frustration relief bonus.

We run $R=30$ replications per condition for $S=200$ steps. Reproducibility uses base seed $42$; run $i$ uses seed $42+i$, so network structure and stochastic draws are reconstructible for each replicate.

\subsubsection{Statistical Methodology}
We analyze final-step metrics across all $120$ runs with non-parametric methods. Pairwise condition contrasts use two-sided Mann--Whitney $U$ tests~\citep{Mann1947} with Bonferroni correction across the full pairwise family, and Cohen's $d$~\citep{Cohen1988} for standardized magnitude (negligible $|d|<0.2$; small $<0.5$; medium $<0.8$; large $\ge 0.8$). We also report $95\%$ bootstrap confidence intervals ($10{,}000$ resamples).

For Bridge $\times$ Trust moderation, we compute seed-paired effects $\Delta_{\mathrm{alone}}=(\mathrm{Bridge\ Only})-(\mathrm{Baseline})$ and $\Delta_{\mathrm{with\ trust}}=(\mathrm{Full\ Model})-(\mathrm{Trust\ Only})$, then apply a Wilcoxon signed-rank test to $\Delta_{\mathrm{with\ trust}}-\Delta_{\mathrm{alone}}$, with Bonferroni correction across interaction metrics. This paired procedure matches the shared-seed design more closely than an unpaired rank-sum test on the two effect vectors.
