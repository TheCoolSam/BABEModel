% Method Section following the ODD+D Protocol

To guarantee absolute transparency and reproducibility, we formalize the Dynamic-BABE (Biased Assimilation \& Behavioral Entrenchment) model via the standardized ODD+D (Overview, Design concepts, Details, and Decision-making) protocol \citep{Grimm2010, Muller2013}. This protocol provides a rigorous, structured architecture. It exposes the micro-level cognitive loops and decision heuristics that govern human interaction---the very forces driving online opinion dynamics.

\subsection{Overview}

\subsubsection{Purpose}
We built the Dynamic-BABE model to dissect the co-evolutionary feedback loop linking interpersonal trust, cognitive biases (such as biased assimilation and the backfire effect), and platform curation. By simulating these interlocking components, we lay bare the mechanics of the Polarization Paradox: superficial feed moderation arrests user exit and secures ad revenue today, only to entomb the social network in hostile ideological silos tomorrow.

\subsubsection{Entities, State Variables, and Scales}
Two entities drive the simulation: \textbf{agents} (users navigating their feeds) and the \textbf{network environment} (the network's structural pathways and the platform's moderation layer).

\subsubsection{Agents:} Each agent $i \in \{1, 2, \dots, N_{\text{agents}}\}$ represents a single user, tracked via several state variables:
\begin{itemize*}
    \item \textbf{Opinion Vector} ($\vec{O}_i \in [-1, 1]^K$): A multi-dimensional ideological signature representing the agent's stance on $K$ distinct social or political issues. The issue dimension $d \in \{1, \dots, K\}$ spans continuously from $-1.0$ (progressive/left) to $+1.0$ (conservative/right).
    \item \textbf{Salience Vector} ($\vec{S}_i \in [0, 1]^K$): An attention allocation vector mapping the relative cognitive importance the agent assigns to each issue. We constrain this vector so that salience sums to unity: $\sum_{d=1}^K S_{i,d} = 1.0$.
    \item \textbf{Cognitive Entrenchment} ($\beta_i \in [\beta_{\min}, \infty)$): A scalar tracking cognitive resistance, dogmatism, or confirmation bias \citep{Chen2021}. Elevated $\beta_i$ values amplify outgroup rejection and fuel stronger backfire repulsion.
    \item \textbf{Behavioral Frustration} ($F_i \in \mathbb{N}_0$): An integer counter tracking the psychological irritation and cognitive dissonance that mount during confrontational, cross-cutting exchanges.
    \item \textbf{Active Status} ($\text{Active}_i \in \{\text{True}, \text{False}\}$): A boolean flag marking platform activity. When frustration breaches the critical threshold $T_c$, the agent permanently exits the platform ($\text{Active}_i = \text{False}$), registering as user churn.
\end{itemize*}

\subsubsection{Network and Platform Environment:} We model the social topology as an undirected, scale-free graph $G = (V, E)$ generated via the Barab\'{a}si-Albert (BA) preferential attachment algorithm \citep{Barabasi1999}. The node set $V$ represents agents, while the edge set $E$ maps communication pathways.
\begin{itemize*}
    \item \textbf{Dyadic Interpersonal Trust} ($T_{ij} \in [0, 1]$): A symmetric weight representing relational capital on the edge $(i, j) \in E$. Trust cushions disagreement and co-evolves with opinion alignment. Disabling the trust dynamic locks $T_{ij}$ at a static, neutral baseline $T_0 = 0.5$ across all edges.
    \item \textbf{Algorithmic Interception Layer}: The platform's computational gatekeeper. When active, it intercepts impending backfire events, neutralizing the psychological sting of deep ideological disagreement.
\end{itemize*}

\subsubsection{Scales:} Time ticks in discrete steps $t \in \{1, 2, \dots, t_{\max}\}$, where each step represents a conversational epoch. Space is purely topological, dictated by network connections. The model populates a scale-free network with $N_{\text{agents}} = 500$ agents and preferential attachment parameter $m_e = 3$, yielding degree distributions that mirror real-world social networks.

\subsubsection{Process Overview and Scheduling}
Each step $t$ triggers a sequence of operations that update opinions, frustration, trust, and churn:
\begin{enumerate*}
    \item \textbf{Randomized Activation Order:} The scheduler shuffles all active agents into a randomized list at the start of each step to eliminate sequential bias.
    \item \textbf{Agent Interaction Loop:} We iterate through each active agent $i$ in the shuffled list:
    \begin{enumerate*}
        \item The agent filters its neighbors to isolate active peers: $\mathcal{N}_i^{\text{active}}(t) = \{j \in \mathcal{N}_i : \text{Active}_j(t) = \text{True}\}$. If this neighborhood is empty, the agent skips its turn.
        \item The agent selects a dialogue partner $j$ from $\mathcal{N}_i^{\text{active}}(t)$ uniformly at random. We set the interaction step size to $k_{\text{step}} = 1$ to capture micro-conversational dynamics.
        \item The directed interaction pipeline $\text{Interact}(i, j)$ executes, updating agent $i$'s opinion vector, accumulating frustration, checking for churn, and updating the symmetric trust $T_{ij}$ on the connecting edge.
    \end{enumerate*}
    \item \textbf{Passive Trust Decay:} Once all active interactions conclude, we apply passive decay to \emph{every} edge $(u, v) \in E$, including edges that were updated during the same step:
    \begin{equation}
        T_{uv}(t+1) = T_{uv}(t) \cdot (1 - \lambda)
    \end{equation}
    \item \textbf{Platform Diagnostics:} The model computes and logs global metrics: opinion polarization $\sigma(t)$, cumulative churn, user frustration, active user count, ingroup/outgroup trust divergence, and opinion-weighted clustering.
    \item \textbf{Termination Check:} The simulation halts when the step count reaches $t_{\max} = 200$, or if all users exit ($N_{\text{active}} = 0$).
\end{enumerate*}

\subsection{Design Concepts}

\subsubsection{Theoretical Background}
We anchor Dynamic-BABE's cognitive architecture in \textbf{Social Judgment Theory} \citep{Sherif1961, Jager2005}. This framework partitions an agent's attitude spectrum into three distinct zones: the Latitude of Acceptance (yielding assimilative agreement), the Latitude of Non-Commitment (resulting in inertia), and the Latitude of Rejection (triggering backfire repulsion).

To formalize cognitive entrenchment ($\beta_i$) and opinion alignment ($A_{ij}$), we adapt the \textbf{Biased Assimilation and Behavioral Entrenchment (BEBA)} model proposed by \citet{Chen2021}, which extends DeGroot's classical consensus dynamics \citep{DeGroot1974}. We merge this with a dynamic trust layer inspired by Slovic's empirical research \citep{Slovic1993}. This integration captures the fundamental asymmetry of trust: relational capital accumulates painfully slowly through agreement but collapses instantly during conflict.

Finally, we operationalize user exit by mapping the accumulation of frustration to the classic \textbf{Exit-Voice-Loyalty (EVL)} framework of \citet{Hirschman1970}.

\subsubsection{Individual Decision-Making}
Agents employ heuristic cognitive updates rather than rational utility maximization, strictly following the bounded rationality principles of the ODD+D protocol.
\begin{itemize*}
    \item \textbf{Objectives:} Agents do not maximize an explicit utility or payoff function. Instead, their immediate psychological objective is to minimize cognitive dissonance. They seek agreeable social contact that reinforces their existing views while avoiding highly confrontational outgroup viewpoints that land in their Latitude of Rejection.
    \item \textbf{Information Processing:} When active, an agent perceives the opinion vector $\vec{O}_j$ and salience weights $\vec{S}_j$ of their chosen dialogue partner. They process this information heuristically by calculating their salience-weighted opinion alignment $A_{ij}$ and checking whether the resulting influence weight lands in their Latitude of Acceptance, Non-Commitment, or Rejection.
    \item \textbf{Adaptive Behavior:} Agents adapt dynamically across two scales. Cognitively, they adjust their opinion vectors $\vec{O}_i$ to assimilate toward agreeable peers or repel away from hostile ones. Behaviorally, they accumulate frustration $F_i$ when clashing with others, leading to permanent exit (churn) if their frustration threshold is breached. Relationally, their dyadic trust $T_{ij}$ adapts to reward agreement and penalize conflict, reshaping future interaction weights.
\end{itemize*}

\subsubsection{Learning}
Although agents lack formal reinforcement learning capabilities, they maintain a relational memory via dyadic trust ($T_{ij}$). They continuously update their assessment of neighbor compatibility. Agreeable, assimilative dialogue slowly accumulates trust, whereas hostile backfires instantly incinerate it. This co-evolving relational memory shapes future influence weights, closing the feedback loop between network relations and cognitive updates.

\subsubsection{Individual Sensing}
Each agent $i$ tracks its direct topological neighbors with perfect accuracy. During dialogue, agent $i$ observes a neighbor's opinion vector $\vec{O}_j$ and salience weights $\vec{S}_j$. Agents remain blind to the state variables, cognitive profiles, and degrees of non-neighboring nodes, and they hold zero global knowledge regarding system-level polarization or platform-level financials.

\subsubsection{Individual Prediction}
Agents react purely to immediate events, operating without forward-looking predictions. They neither anticipate neighbor opinion shifts nor forecast their own impending exit as frustration mounts toward the churn threshold.

\subsubsection{Interaction}
Interactions unfold locally, dyadically, and directionally. While trust updates symmetrically across the edge $(i, j)$, opinion and frustration updates execute from the perspective of the active agent receiving the communication. The platform's bridging algorithm acts as an external filter, intercepting high-friction exchanges to suppress the behavioral symptoms of disagreement.

\subsubsection{Collectives}
No formal collectives (such as political parties or coalitions) exist in our model. However, functional collectives emerge endogenously through conversational dynamics. Agents coalesce into two opposing ideological factions based on their opinion signs. These emergent camps govern the flow of trust and drive the self-organization of network clusters.

\subsubsection{Heterogeneity}
We introduce substantial heterogeneity across several parameters:
\begin{itemize*}
    \item \textbf{Ideological Camps:} Bipolar initial opinions split the population into two opposed factions.
    \item \textbf{Issue Salience:} Diverse attention allocations drawn from a Dirichlet distribution mean agents prioritize issues differently.
    \item \textbf{Cognitive Entrenchment:} The entrenchment parameter $\beta_i$ varies across agents, mixing dogmatic and open-minded individuals.
    \item \textbf{Network Topology:} The Barab\'{a}si-Albert topology yields a heavy-tailed degree distribution where a few highly connected hubs exert massive social influence while the rest have minimal reach.
\end{itemize*}

\subsubsection{Stochasticity}
We integrate stochasticity to capture social noise and scheduling dynamics:
\begin{itemize*}
    \item The preferential attachment model generates network topologies stochastically.
    \item Shuffling shatters sequential order by randomizing agent activation at each step.
    \item Dialogue partner selection is stochastic, choosing randomly from active neighbors.
    \item The bridging algorithm operates probabilistically, intercepting rejection events with an efficacy rate of $E = 46\%$.
    \item Initial values for opinion, salience, and entrenchment are drawn randomly from their respective probability distributions.
\end{itemize*}

\subsubsection{Observation}
We record the system's trajectory at the end of each step by collecting system-level and agent-level diagnostics:
\begin{itemize*}
    \item \textbf{Global Polarization ($\sigma(t)$):} The root-mean-square (RMS) of per-dimension opinion standard deviations across active agents.
    \item \textbf{Active User Count ($N_{\text{active}}$):} The sum of active nodes.
    \item \textbf{Churn Rate:} The cumulative fraction of the population that has permanently exited.
    \item \textbf{Average Frustration:} The mean frustration across active users.
    \item \textbf{Platform Revenue ($R(t)$):} Total advertising earnings, which drop when polarization triggers advertiser flight.
    \item \textbf{Trust Segregation Ratio:} The ratio of mean ingroup trust to mean outgroup trust.
    \item \textbf{Opinion-Weighted Clustering:} The density of triadic relationships where all three connected nodes share the same opinion pole.
\end{itemize*}

\subsection{Details}

This section details the mathematical formulations and structural rules governing initialization, dialogue, trust co-evolution, user exit, and platform monetization.

\subsubsection{Initialization}
At $t = 0$, the model builds an undirected, scale-free network $G$ of $N_{\text{agents}} = 500$ nodes with attachment parameter $m_e = 3$.

To seed a pre-polarized society, we initialize opinion vectors $\vec{O}_i \in [-1, 1]^K$ ($K = 2$ issues) via a \textbf{bipolar split}. Each agent is assigned a camp pole $\pi_i \in \{-1, +1\}$ with equal probability. Independently for each issue dimension $d$, extremity is drawn from a uniform interval and scaled by the pole:
\begin{equation}
    O_{i,d}(0) = \Pi_{[-1, 1]}\Big( \pi_i \cdot U_{i,d}(0.4, 1.0) \Big)
\end{equation}
where $U_{i,d}(0.4, 1.0)$ denotes an independent draw from $\mathcal{U}(0.4, 1.0)$ and $\Pi_{[-1, 1]}$ clips opinions to $[-1, 1]$. The expected absolute extremity is $0.7$, yielding two opposed, pre-polarized factions without additional Gaussian noise.

We draw each agent's salience vector $\vec{S}_i$ from a symmetric Dirichlet distribution:
\begin{equation}
    \vec{S}_i \sim \text{Dirichlet}(\vec{\alpha})
\end{equation}
where $\vec{\alpha} = [1, 1]^T$ for $K = 2$ issues, ensuring that $S_{i,d} \in [0, 1]$ and $\sum_{d=1}^K S_{i,d} = 1.0$.

To model cognitive dogmatism, we draw agent entrenchment $\beta_i$ from a normal distribution and floor it to prevent negative resistance:
\begin{equation}
    \beta_i = \max\Big( \beta_{\min},\, \nu_i \Big), \quad \nu_i \sim \mathcal{N}(\mu_{\beta},\, \sigma_{\beta}^2)
\end{equation}
with parameters set to default values: $\beta_{\min} = 0.5$, $\mu_{\beta} = 4.0$, and $\sigma_{\beta} = 1.5$.

All active network edges $(u, v) \in E$ begin with symmetric dyadic trust set to a uniform starting value:
\begin{equation}
    T_{uv}(0) = T_0 = 0.5
\end{equation}
Every agent begins the simulation with zero behavioral frustration ($F_i(0) = 0$).

\subsubsection{Input Data}
The Dynamic-BABE model is a theoretical, self-contained simulation and does not ingest external empirical input data for its execution.

\subsubsection{Submodels}

\subsubsection{Dialogue Dynamics and Opinion Updates:} Upon activation, agent $i$ randomly selects an active neighbor $j$ for dialogue, processing the incoming opinion through a multi-stage cognitive pipeline.

\subsubsection{Step 1: Salience-Weighted Opinion Alignment ($A_{ij}$)}
We calculate the ideological distance between receiver $i$ and sender $j$ as a salience-weighted dot product:
\begin{equation}
    A_{ij} = \sum_{d=1}^K O_{i,d} \cdot \left(\frac{S_{i,d} + S_{j,d}}{2}\right) \cdot O_{j,d}
\end{equation}
This formulation captures a key psychological reality: mutually important issues---where salience is high---contribute disproportionately to perceived agreement or disagreement. Because opinions are bounded in $[-1, 1]$ and average saliences sum to $1.0$, the alignment spans $A_{ij} \in [-1, 1]$, where $+1.0$ represents perfect alignment on highly valued topics and $-1.0$ marks absolute ideological clash.

\subsubsection{Step 2: Perceived Influence Weight ($w_{ij}$)}
Adapting the BEBA model \citep{Chen2021}, we establish a baseline influence weight based on the receiver's cognitive entrenchment and opinion alignment:
\begin{equation}
    w_{ij}^{\text{base}} = 1.0 + \beta_i A_{ij}
\end{equation}
Under the \textbf{Dyadic Trust} system, relational trust modulates this weight, serving as a positive cognitive buffer:
\begin{equation}
    w_{ij} = 1.0 + \beta_i A_{ij} + \gamma_T T_{ij}
\end{equation}
where $\gamma_T \geq 0$ represents the trust influence coefficient (\texttt{TRUST\_INFLUENCE} = 0.3) and $T_{ij} \in [0, 1]$ represents the dyadic trust. This trust buffer mathematically models the relational buffer that keeps relationships intact during disagreement: high trust elevates the influence weight, preventing debate from deteriorating into hostile backfires. When trust co-evolution is disabled, the model sets $T_{ij} = 0$ dynamically in the weight equation, yielding the baseline form $w_{ij} = 1.0 + \beta_i A_{ij}$. This represents the unmodulated, baseline cognitive state and aligns the theoretical specification with our simulation codebase.

\subsubsection{Step 3: Social Judgment Zone Classification}
Unlike the collective, synchronous averaging of Chen et al. \citep{Chen2021}, we translate this cognitive logic into a local, pairwise interaction paradigm. To track individual metrics like frustration, churn, and algorithmic interventions, we classify interactions using Social Judgment Theory \citep{Sherif1961, Jager2005}. The perceived influence weight $w_{ij}$ dictates the interaction zone:
\begin{equation}
    \text{Zone}(w_{ij}) = \begin{cases}
        1 \quad (\text{Latitude of Acceptance}) & \text{if } w_{ij} > \tau_{\text{assim}} \\
        2 \quad (\text{Latitude of Non-Commitment}) & \text{if } 0.0 \leq w_{ij} \leq \tau_{\text{assim}} \\
        3 \quad (\text{Latitude of Rejection}) & \text{if } w_{ij} < 0.0
    \end{cases}
\end{equation}
where $\tau_{\text{assim}} = 0.3$ represents the assimilation threshold. We model these latitude boundaries as stylized, uniform thresholds across the population for mathematical tractability and to isolate the systemic co-evolutionary feedback loops. In empirical social systems, these latitudes are highly subjective and dynamic, varying widely across individuals based on issue-specific emotional involvement and prior ideological extremity. We discuss the implications of this stylized assumption in Section~\ref{sec:discussion}.

\subsubsection{Step 4: Algorithmic Moderation (The Bridge Algorithm)}
When active, the platform's bridging algorithm intercepts backfire (Zone 3) events with an efficacy rate of $E = 0.46$:
\begin{equation}
    w_{ij} \leftarrow 0.0, \quad \text{Zone}(w_{ij}) \leftarrow 2 \quad \text{with probability } E
\end{equation}
Interception neutralizes the opinion repulsion, downgrading the conflict to Zone 2 (Ignore). In addition, successful moderation grants a frustration relief bonus to preserve the agent's psychological state. We model this frustration relief bonus ($B_{hb} = 2$) as the platform's active delivery of "dopaminergic comfort" or "algorithmic reinforcement" (e.g., stochastically substituting a hostile outgroup post with a soothing, highly engaging ingroup post or distracting entertainment). This intervention actively diverts attention, helping to soothe and heal preexisting cognitive friction.

\subsubsection{Step 5: Opinion Update Rules}
We update the opinion vector $\vec{O}_i$ depending on the final interaction zone:
\begin{itemize*}
    \item \textbf{Zone 1 (Assimilation):} The agent assimilates toward the sender using a DeGroot-style consensus update:
    \begin{equation}
        \vec{O}_i(t+1) = \Pi_{[-1, 1]}\left(\vec{O}_i(t) + \mu_{ij} \Big(\vec{O}_j(t) - \vec{O}_i(t)\Big)\right)
    \end{equation}
    where we attenuate the step size $\mu_{ij}$ by the agent's cognitive entrenchment:
    \begin{equation}
        \mu_{ij} = \frac{w_{ij}}{1.0 + \beta_i}
    \end{equation}
    This ensures that highly entrenched agents (high $\beta_i$) make smaller opinion adjustments, reflecting cognitive resistance. The vector-wise operator $\Pi_{[-1, 1]}$ acts element-wise to clip (clamp) updated opinions to the valid range $[-1.0, 1.0]$. We note that under conditions of absolute alignment ($A_{ij} = 1.0$) and high dyadic trust ($T_{ij} = 1.0$), the influence step size can stochastically exceed unity ($\mu_{ij} > 1.0$). While classical DeGroot consensus models enforce a strict convex combination ($\mu_{ij} \in [0, 1]$) to maintain the convex hull of opinions, our formulation permits this mathematical "overshoot." In the context of relational network dynamics, this represents a "passionate consensus" or "social reinforcement effect"---a psychological phenomenon where deep interpersonal trust and absolute agreement trigger cognitive enthusiasm, prompting the receiver to adopt a stance even more extreme than their trusted peer.
    
    \item \textbf{Zone 2 (Non-Commitment):} The interaction is ignored, leaving the opinion vector unchanged:
    \begin{equation}
        \vec{O}_i(t+1) = \vec{O}_i(t)
    \end{equation}
    
    \item \textbf{Zone 3 (Backfire):} The agent experiences ideological repulsion and pushes its opinion vector away from the sender:
    \begin{equation}
        \vec{O}_i(t+1) = \Pi_{[-1, 1]}\left(\vec{O}_i(t) + \text{repulsion}_{ij} \Big(\vec{O}_i(t) - \vec{O}_j(t)\Big)\right)
    \end{equation}
    where the repulsion step size is:
    \begin{equation}
        \text{repulsion}_{ij} = \frac{|w_{ij}|}{1.0 + \beta_i}
    \end{equation}
    This repulsive force drives agent $i$ further toward the ideological extremes, modeling the backfire effect, subject to the same element-wise clipping operator $\Pi_{[-1, 1]}$.
\end{itemize*}

\subsubsection{Behavioral Frustration and User Churn:}
Unmitigated disagreements accumulate psychological costs, which we model as behavioral frustration $F_i$:
\begin{itemize*}
    \item \textbf{Frustration Accrual (Backfire):} Unmitigated backfires (Zone 3) increment frustration:
    \begin{equation}
        F_i(t+1) = F_i(t) + 1
    \end{equation}
    \item \textbf{Frustration Healing (Assimilation):} Assimilative dialogue (Zone 1) relieves cognitive dissonance, healing frustration at a constant rate $H = 1$:
    \begin{equation}
        F_i(t+1) = \max\Big(0,\, F_i(t) - H\Big)
    \end{equation}
    \item \textbf{Moderation Relief Bonus:} Successful algorithmic interception spares the agent the backfire and grants a mental relief bonus $B_{hb} = 2$:
    \begin{equation}
        F_i(t+1) = \max\Big(0,\, F_i(t) - B_{hb}\Big)
    \end{equation}
\end{itemize*}

At the end of each interaction, the agent checks its psychological tolerance. When cumulative frustration breaches the churn threshold $T_c = 15$, the user permanently exits the platform ($\text{Active}_i = \text{False}$):
\begin{equation}
    \text{Active}_i(t+1) = \begin{cases}
        \text{False} & \text{if } F_i(t+1) > T_c \\
        \text{Active}_i(t) & \text{otherwise}
    \end{cases}
\end{equation}
Churned users freeze instantly. They cease all dialogue, drop out of the communication graph, and generate zero advertising revenue.

\subsubsection{Dyadic Trust Co-evolution:}
Under the dynamic condition, dyadic trust $T_{ij}$ co-evolves with dialogue outcomes:
\begin{equation}
    T_{ij}(t+1) = \begin{cases}
        \min\Big(1.0,\, T_{ij}(t) + \delta_+\Big) & \text{if } \text{Zone}(w_{ij}) = 1 \text{ (Assimilation)} \\
        \max\Big(0.0,\, T_{ij}(t) - \delta_-\Big) & \text{if } \text{Zone}(w_{ij}) = 3 \text{ (Backfire)} \\
        T_{ij}(t) & \text{if } \text{Zone}(w_{ij}) = 2 \text{ (Ignore)}
    \end{cases}
\end{equation}
where $\delta_+ = 0.02$ represents the slow accumulation of trust during agreement, and $\delta_- = 0.05$ captures the rapid collapse triggered by conflict. The resulting asymmetry ratio ($\delta_- / \delta_+ = 2.5$) mathematically formalizes Slovic's empirical trust asymmetry principle: social relationships are highly fragile, and conflict destroys trust much faster than cooperation builds it.

Because social ties naturally wither without active engagement, we apply a passive decay filter to every edge $(u, v) \in E$ at the end of each step:
\begin{equation}
    T_{uv}(t+1) = T_{uv}(t) \cdot (1 - \lambda)
\end{equation}
where $\lambda = 0.001$ represents the passive erosion rate.

\subsubsection{Platform Revenue:} The social media platform monetizes active users, generating ad revenue at each step $t$. Advertisers flee volatile feeds, imposing a heavy \textbf{Brand Safety Penalty} if global polarization crosses the critical cliff:
\begin{equation}
    R(t) = N_{\text{active}}(t) \cdot r_{\text{ad}} \cdot M_{\text{safety}}(t)
\end{equation}
Here, $N_{\text{active}}(t)$ represents the active user count, $r_{\text{ad}} = \$1.00$ is the base ad rate per user, and $M_{\text{safety}}(t)$ represents the brand safety multiplier:
\begin{equation}
    M_{\text{safety}}(t) = \begin{cases}
        M_{\text{safe}} = 1.0 & \text{if } \sigma(t) < \tau_{\text{cliff}} \\
        M_{\text{unsafe}} = 0.4 & \text{if } \sigma(t) \geq \tau_{\text{cliff}}
    \end{cases}
\end{equation}
where $\tau_{\text{cliff}} = 0.6$ represents the polarization cliff threshold. We calculate global polarization $\sigma(t)$ as the root-mean-square (RMS) of per-dimension standard deviations across active agents:
\begin{equation}
    \sigma(t) = \sqrt{\frac{1}{K} \sum_{d=1}^K \mathrm{SD}\Big(\{O_{i,d}(t) : i \in \mathcal{A}(t)\}\Big)^2}
\end{equation}
where $\mathcal{A}(t) = \{i \in V : \text{Active}_i(t) = \text{True}\}$ and $\mathrm{SD}$ denotes the population standard deviation within dimension $d$. This formulation avoids the ``data flattening'' trap: averaging opinions across dimensions can cancel opposed extremes (e.g., $[+1,-1]$), whereas per-dimension dispersion preserved under RMS does not.

Ingroup and outgroup trust metrics classify an agent's pole by $\mathrm{sign}(\overline{O}_i)$, the sign of the mean opinion across issues. Agents with mean opinion exactly zero ($\mathrm{sign}(0)=0$) are rare under bipolar initialization but, when present, are treated as a distinct zero pole for edge classification; we discuss this edge case as a limitation.
